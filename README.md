# EEUU-Canada-food-supplements-2024-supply.
Este es mi primer análisis de datos en el que estudio la demanda de suplementos alimenticios en Estados Unidos y Canadá durante los últimos 5 años. He elaborado una gráfica que verifica la información de un data set obtenido del FDA (food and drugs deartment) de Estados Unidos y he elaborado un comentario explicativo de la situación.
